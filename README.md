# Braise — site vitrine de restaurant

Site statique (HTML / CSS / JS, sans dépendance). Ouvrir `index.html` dans un navigateur.

- `index.html` — contenu (carte, galerie, avis, réservation, infos)
- `styles.css` — design (thème sombre, typographie Cormorant + Inter, animations)
- `script.js` — interactions (préchargement, braises animées, onglets de la carte, slider d'avis, parallaxe, formulaire)

Les photos proviennent d'Unsplash ; remplacez-les par vos propres visuels.
Le formulaire de réservation est simulé côté navigateur : branchez-le à votre outil (TheFork, Zenchef, e-mail…) pour recevoir les demandes.
